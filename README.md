# Maestro-write-disser-about-stereopictyre
Репозиторий НИР студента Крушинов Р.Д. в ИТМО направления Математическое и компьютерное моделирование

    Информация об окружающей среде, получаемая с помощью стереокамеры, подвергается алгоритмической обработке с использованием классических и нейросетевых методов для построения трёхмерной модели объектов и пространства.
    Одним из ключевых этапов обработки является фильтрация выбросов и ложных соответствий. Существующие методы имеют ограничения по точности, устойчивости и вычислительной эффективности, что определяет актуальность их сравнительного анализа. Именно этому этапу посвящена данная НИР.
    Растёт потребность в бесконтактном определении расстояний, трекинге объектов и анализе сцен в условиях, где использование лидаров и дальномеров технически затруднено или экономически нецелесообразно. Перспективной альтернативой выступают системы стереоскопического зрения. Вместе с этим есть запрос на повышение точности и вычислительной эффективности систем.
    Цель НИР-1:
    Провести сравнительный анализ классических и нейросетевых методов фильтрации выбросов, оценить их точность, устойчивость и вычислительную эффективность, а также определить условия, при которых каждый из подходов обеспечивает наилучшее качество восстановления трёхмерной структуры сцены.
    Цель глобальная:
    Нахождение слабых мест текущих алгоритмов фильтрации и доказательство таковых, возможное их исправление и повышение вычислительной эффективности методов.
